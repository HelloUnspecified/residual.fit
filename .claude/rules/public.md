# public/

- `public/s/index.html` is the share page shown when the app isn't installed. Its CSP (in `_headers`) is `default-src 'none'; script-src 'self'`: no inline scripts, no external fonts, images or fetches. All logic goes in `public/s/share.js`.
- `share.js` renders untrusted data from the URL hash. Write it to the DOM through `textContent` only, never `innerHTML`, and keep the existing size cap.
- `/s/` is `Disallow`ed in `robots.txt` and must stay out of the sitemap.
- `.well-known/apple-app-site-association` must be served as `application/json` with no redirect and no file extension. `appIDs` is `<TEAM_ID>.<bundle id>`; change it only together with the app's bundle id or team.
- `_headers`: every matching block applies and the later block wins on conflicts, so the site-wide `/*` block stays first. These headers don't apply to Pages Functions.
- `og.png` is generated by `npm run og`; don't edit it by hand.
